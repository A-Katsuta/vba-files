# 表示形式の確認ツール.bas ガイド

## 概要
表示形式の確認ツール (`表示形式の確認ツール.bas`) は、ワークブック内のセルや指定範囲について、表示形式・数値フォーマット・警告対象となる不一致をレポート化する VBA モジュールです。日付や通貨などの数値が想定どおりのフォーマットで管理されているかを簡単に検証でき、帳票の体裁チェックやデータ受け入れ時の QA 作業を効率化します。

## 前提条件
- Windows 環境で動作する Microsoft Excel 2016 以降
- 対象ブックに `表示形式の確認ツール.bas` をインポート済みであること
- マクロ有効形式 (`.xlsm` など) での保存
- ログ出力先として利用するシート (例: `FormatCheckLog`) を事前に準備

## 主な機能
- **セル範囲の一括検査**: 指定したワークシートまたは名前定義範囲を走査し、表示形式とセルの値タイプを突合。
- **期待フォーマットとの比較**: 設定シートやハードコードしたマッピング表と照合し、逸脱を抽出。
- **レポート出力**: 判定結果を一覧表としてシートへ書き出し、件数ハイライト・メッセージを付与。
- **再検査の自動化サポート**: ボタンやショートカットからワンクリック実行できるヘルパープロシージャを同梱。

## ファイル構成と主なプロシージャ
| プロシージャ | 役割 |
| --- | --- |
| `RunFormatAudit()` | ユーザーが呼び出すエントリーポイント。対象範囲の決定とログ初期化を担当。 |
| `InspectRangeFormat(targetRange As Range)` | 個々のセルを走査し、フォーマット情報を収集。 |
| `CompareWithExpected(settings As Collection, info As FormatInfo)` | 期待値との比較処理。差異があればメッセージを返却。 |
| `WriteResultRow(logSheet As Worksheet, result As AuditResult)` | レポートシートへの書き込みとスタイル適用。 |
| `LoadFormatSettings()` | 設定シート/JSON などから期待フォーマットを読み込むヘルパー。 |

> **補足**: モジュール内で独自の `FormatInfo` や `AuditResult` といったユーザー定義型を使う場合は、`Option Private Module` を避けることで他モジュールからの再利用が容易になります。

## 使い方
1. Excel の VBA エディター (`ALT + F11`) を開き、`表示形式の確認ツール.bas` を対象プロジェクトへインポートします。
2. 設定シート上で、列名や期待フォーマット (例: `yyyy/mm/dd`, `#,##0.00`) を表形式で登録します。
3. 必要に応じて `RunFormatAudit` に渡すパラメータ (対象シート名、チェック範囲、ログシート名など) を編集します。
4. Excel 上のボタン、クイックアクセスツールバー、またはショートカットに `RunFormatAudit` を割り当てて実行します。
5. 結果はログシートに出力されます。ステータス列をフィルターすることで要修正セルを素早く確認できます。

## カスタマイズのヒント
- **閾値の調整**: 金額や百分率などの誤差許容を `CompareWithExpected` 内のロジックで制御します。
- **除外リスト**: チェック対象外の列/セルを `Collection` や `Dictionary` に登録し、`InspectRangeFormat` 実行時にスキップします。
- **結果の可視化**: 条件付き書式を併用し、逸脱セルに色付けするとレビューが捗ります。
- **他モジュール連携**: ログを CSV 出力する `Logger.bas` などが存在する場合は、`WriteResultRow` でフックを呼び出すことでワークフロー連携が可能です。

## トラブルシューティング
| 症状 | 対処 |
| --- | --- |
| レポートが空になる | 対象範囲が正しく渡されているか、設定シートが最新化されているかを確認。 |
| 期待フォーマットを読み込めない | `LoadFormatSettings` の参照先 (シート名/ファイルパス) を見直し、参照切れがないかを確認。 |
| 実行時エラー 9 (インデックス範囲外) | ログシート名が存在しない場合に発生。シートを追加するかコード内の定数を修正。 |
