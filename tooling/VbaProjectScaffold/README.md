# VBA Project Scaffold (Phase 1)

- build.bat で `tools/Build-VbaProject.ps1` を実行し、`template/BaseTemplate.xltm` から `.xlsm` を生成します。
- VBA モジュールは `src/vba/modules` と `src/vba/classes` に配置します。

## 使い方
1. `template/BaseTemplate.xltm` が無い場合は自動作成（失敗したら手動で作成）
2. `build.bat` をダブルクリック
3. 成果物は `build/Output_YYYYMMDD_HHMMSS.xlsm`
