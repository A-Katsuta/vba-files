# フェーズ1 自動ビルドシステム 取扱説明書

この文書は、フェーズ1 詳細設計書（VBA開発自動化MVP）で設計されたビルド仕組みを、IT 知識が少ない方でも運用できるようにまとめたものです。ソースコードを更新して成果物を作るまでの流れと、困ったときの対処方法を順番に紹介します。

---

## 1. システムの役割
- Excel のテンプレートと VBA コードを自動で組み合わせ、最新の `.xlsm` ファイルを作ります。
- 参照設定や保存処理を自動化し、手作業でのミスを防ぎます。
- ビルド履歴とログを残すので、失敗したときも原因をたどりやすくなっています。

出力ファイルは `build` フォルダに時刻付きの名前で生成されます。

---

## 2. 事前に準備するもの
1. **Windows 10 / 11 のパソコン**
2. **Microsoft Excel 2016 以上 / Microsoft 365**
3. **PowerShell 5.1**（Windows に標準で含まれています）
4. 以下のフォルダ一式（Zipなどで配布されています）
   - `build.bat`
   - `tools/Build-VbaProject.ps1`
   - `template/BaseTemplate.xltm`
   - `src/vba/modules/*.bas`、`src/vba/classes/*.cls`
   - `build/`、`logs/`、`config/` フォルダ

フォルダ名は自由ですが、1つの場所（例: `C:\VBA-Automation\`）にまとめて配置してください。

---

## 3. フォルダ構成の見方
| 場所 | 中身 | やること |
|------|------|----------|
| `build.bat` | ビルド開始用バッチ | ダブルクリックで実行するだけ |
| `tools/Build-VbaProject.ps1` | PowerShell スクリプト | 変更不要（開発者のみ編集） |
| `template/BaseTemplate.xltm` | Excel テンプレート | レイアウト調整があるときだけ編集 |
| `src/vba/modules` | 標準モジュール(.bas) | VBA コードを更新する場所 |
| `src/vba/classes` | クラスモジュール(.cls) | 必要なクラスを配置 |
| `build/` | 生成された .xlsm の置き場 | 完成物を確認・配布する |
| `logs/` | 実行ログ | エラーが出たときに参照 |
| `config/` | 将来の設定用ファイル | 現状はそのままで OK |

---

## 4. 初めて使うときの設定（約15分）
1. Excel を開き、「ファイル」→「オプション」→「セキュリティ センター」→「セキュリティ センターの設定」を開きます。
2. 「マクロの設定」で、運用ルールに合わせて **マクロを有効化** します（推奨: “警告を表示してすべてのマクロを無効にする” を選び、必要なときに有効化）。
3. 「開発者向けのマクロ設定」で **「VBA プロジェクト オブジェクト モデルへのアクセスを信頼する」** にチェックを入れます。
4. 設定後、Excel を一度終了し、PC を再起動すると安定します。

---

## 5. 日常のビルド手順（5分程度）
1. **コードを準備**: `src/vba` 内の `.bas` や `.cls` を最新の内容に置き換え、保存します。
2. **テンプレートを調整（必要なときだけ）**: `template/BaseTemplate.xltm` を開き、シート構成やボタンを更新して保存します。
3. **ビルド実行**: `build.bat` をダブルクリックします。
   - 黒い画面に進行状況が表示されます。
   - 実行中は他の Excel をできるだけ閉じておくと安全です。
4. **結果確認**: 画面に「ビルドが正常に完了しました」と出たら Enter キーで閉じます。
5. `build` フォルダを開き、日付付きファイル（例: `Output_20250918_104500.xlsm`）が作成されているか確認します。

---

## 6. 出力ファイルを確認・配布する
1. `build` フォルダの最新ファイルをダブルクリック。
2. マクロを有効化し、目的のボタンやコマンドが期待通り動くかチェックします。
3. 問題なければ、ファイル名をわかりやすく変更し、共有フォルダやメールで配布します。

---

## 7. よくある運用シナリオ
- **新しいモジュールを追加したい** → `src/vba/modules` に `.bas` をコピーし、ビルドし直します。
- **クラスを追加したい** → `src/vba/classes` に `.cls` を保存します。
- **テンプレートにボタンを追加したい** → `template/BaseTemplate.xltm` を直接編集します。
- **古い成果物を整理したい** → `build` フォルダの不要ファイルを削除またはバックアップします。
- **作業履歴を残したい** → `logs` フォルダのログを保存、共有します。

---

## 8. 困ったときのチェックリスト
| 状況 | 考えられる原因 | 対処方法 |
|------|----------------|----------|
| エラーで止まる / “テンプレートが見つかりません” | テンプレートを移動・削除した | `template/BaseTemplate.xltm` を元の場所に戻す |
| “VBA プロジェクトへのアクセスが拒否されました” | Excel の開発者設定が未完 | セクション4の手順を見直し、Excel を再起動 |
| PowerShell の警告が出る | 実行ポリシー制限 | 管理者権限で PowerShell を開き `Set-ExecutionPolicy RemoteSigned` を実行（会社ルール要確認） |
| Excel が終了してもプロセスが残る | ビルド途中で中断した | タスクマネージャーで Excel を終了し、再度ビルド |
| 生成ファイルが開けない | 共有フォルダでロック中 | 他の利用者が開いていないか確認。必要ならコピーして別名で開く |

---

## 9. 定期的にやるとよいこと
- **月1回**: `logs` フォルダの古いログ（30日以上前）を削除
- **週1回**: `build` フォルダの不要な成果物を整理
- **大きな変更前**: フォルダ一式をコピーしてバックアップ
