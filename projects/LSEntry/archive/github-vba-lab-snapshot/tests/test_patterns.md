# LS入力マクロ テストパターン

本書では `LS入力` ブックを対象とした主要マクロのテストパターンを示す。各テストは手動またはテスト支援マクロ `RunAllTests` で実行できるように設計する。

マスタ（「マスタ」シート）の ListObject `tblMaster` と `Master_*` 系名前定義（例: `Master_Table`、`Master_WorkNumber`、`Master_WorkCode`）を前提にテストを実施する。各テストでは `EnsureMasterReady` の結果が適切に反映され、マスタの内容が最新であることを確認する。

## 1. GetOutlookSchedule (ModGetOutlookSch)
| 番号 | 条件 | 期待結果 |
| --- | --- | --- |
| 1-1 | C3 に有効な日付を設定し予定が存在 | 時刻順に予定が C8 行以降へ出力される |
| 1-2 | C3 が空 | 取得処理が中断されエラーメッセージを表示 |
| 1-3 | 予定が 0 件 | ヘッダーのみを表示し「予定がありません」を通知 |
| 1-4 | マスタの `Master_Table` が存在しない | 処理が中断され、「マスタのテーブルが見つからない」旨のエラーメッセージが表示される |
| 1-5 | 件名がマスタの照合ワードに一致 | F 列に推奨作番、G 列に推奨作番名称、H 列に推奨作業コード、I 列に推奨作業コード名称、J 列に照合ワードが反映される |
| 1-6 | 件名が複数行の照合ワードに一致 | 最初に一致した行（シート上の並び順）が反映され、完了メッセージには未一致以外の警告は表示されない |
| 1-7 | 件名がマスタに存在しない | F〜J 列は空白のままとなり、完了メッセージに未一致警告が表示される |
| 1-8 | Outlook が起動していない | Outlook を起動し予定取得が完了する |
| 1-9 | `ExcludeKeywords` に「除外テスト」を設定し、同キーワードを含む予定と含まない予定が混在 | 除外対象の予定は出力されず、完了メッセージの件数が出力行数と一致する（`tests/outlook_schedule_testdata.md` を参照） |

## 2. ClearInputData (ModDataClear)
| 番号 | 条件 | 期待結果 |
| --- | --- | --- |
| 2-1 | 両シートが保護されていない | 指定範囲の値がクリアされる |
| 2-2 | シートが保護されている | パスワード入力後にクリアされ保護が復元される |
| 2-3 | ユーザーが確認ダイアログでキャンセル | 何も変更されない |

## 3. TransferDataToMonthlySheet (ModDataTransfer)
| 番号 | 条件 | 期待結果 |
| --- | --- | --- |
| 3-1 | D4 に日付があり作業時間が `1:30` 形式 | 月次シートに 90 分が転記される |
| 3-2 | D4 が空で D3 に日付 | D3 の日付で転記される |
| 3-3 | マスタに存在するが月次シートに未追加の作番×作業コード | マスタの作番（`Master_WorkNumber`）と作業コード（`Master_WorkCode`）を照合し、対応列を追加。ヘッダーと書式は既存列から継承される |
| 3-4 | 既存セルに値がある | 上書きされ J3 に重複ログが追記される。マスタで定義された作番・作業コード名は変更されない |
| 3-5 | 不正な時間形式 | エラー表示され転記されない |

> **補足:** 転記テストではマスタの名前定義が月次シートと矛盾していないか（例: 同じ作番・作業コードのヘッダーが `Master_WorkNumber` / `Master_WorkCode` の値と一致しているか）を事前に確認する。

## 4. ClearMonthlyDataAndRefreshCalendar (ModMonthlyMaintenance)

| --- | --- | --- |

## 5. Worksheet_BeforeDoubleClick (ダブルクリック削除r1)
| 番号 | 条件 | 期待結果 |
| --- | --- | --- |
| 5-1 | データ取得シート B10 をダブルクリック | 同行の C〜F および H 列がクリアされる |
| 5-2 | B 列以外をダブルクリック | 何も起こらない |
| 5-3 | 対象シートが保護中 | パスワード解除後にセルがクリアされ保護が復元される |

## 6. テスト支援マクロ (ModTestRunner)
| 番号 | 条件 | 期待結果 |
| --- | --- | --- |
| 6-1 | `RunAllTests` を実行 | `Test_GetOutlookSchedule` がマスタ参照を含む自動入力処理を呼び出し、続けて既存テスト（入力クリア・転記・月次メンテ・ダブルクリック）が順番に完走する |
| 6-2 | `Test_TransferDataToMonthlySheet` を単体実行 | マスタの作番・作業コード情報を使用した列解決が行われ、3章のパターン 3-3/3-4 を再現できる |
