### 付録A: 主処理フロー
```mermaid
flowchart TD
  A[Outlook予定取得
(C3に日付入力)] --> B[統合マスタ照合
(分類・推奨値出力)]
  B --> C[データ登録シートで
作番・作業コード・時間入力]
  C --> D[転記実行
(集計→列解決→書込み)]
  D --> E{既存値あり?}
  E -->|Yes| F[セルを黄色でハイライト
J3に重複ログ追記]
  E -->|No| G[次データ]
  F --> G
  G --> H[処理件数ダイアログ
コピー機能で共有]
```

flowchart LR

  P --> Q[シート保護をUserInterfaceOnlyで復元]

### 参考: 仕様として問題ない事項
- `TransferDataToMonthlySheet` は作番・作業コード・時間のいずれかが空欄の場合、その行を集計対象外とする設計です。運用上は入力前に確認する前提とし、メッセージは表示しません。【F:LS入力/ModDataTransfer.bas†L505-L580】
- `CopyLatestDataToClipboard` は収集結果が 0 件の場合にエラーを発生させ、利用者へメッセージを表示します。時間が未入力の状態での誤操作を防止するための仕様です。【F:LS入力/ModDataTransfer.bas†L909-L950】
- `ClearInputData` は作番・作業コードを保持し、推奨値列と時間・日付セルのみを初期化します。既存行のひな形を活用したい運用に適しています。【F:LS入力/ModDataClear.bas†L85-L108】
