# LS入力 r1 説明書

## このブックについて
- Outlook の予定を読み込み、日々の活動を「データ取得」「データ登録」「月次データ」の3つのシートで整理する Excel ブックです。
- 作業内容を正しく記録すると、月次集計が自動で整い、勤務実績や報告資料を作りやすくなります。

## 初期設定の流れ（最初に一度だけ）
1. **ブックを開く**  
   - Windows 版 Excel でファイルを開き、表示されるメッセージに従ってマクロを有効にします。  
   - Outlook を普段通り起動し、予定が確認できる状態にしておきます。
2. **統合マスタの確認**  
   - シート「統合マスタ」にある一覧表に、担当する作業のキーワードや分類が登録されています。  
   - 足りない項目があれば追記し、名称に間違いがないか確認します。
3. **初期設定ボタンの実行**  
   - シート上部の「初期設定」ボタンを押すと、月次シートの列と入力用の選択肢が最新情報に更新されます。  
   - 完了メッセージが表示されたら初期設定は終了です。

## 普段の使い方
1. **予定の読み込み（データ取得シート）**  
   - セル C3 に集計したい日付を入力し、「予定を取得」ボタンを押します。  
   - Outlook の予定が一覧表に表示されます。件名や時間を確認し、不要な行は削除してください。
2. **作業内容の整理（データ登録シート）**  
   - 予定の内容を確認しながら、作番や作業コード、作業時間を入力します。  
   - 必要に応じて区分や備考も埋めてください。
3. **月次集計への反映（月次データシート）**  
   - 「集計を更新」ボタンを押すと、データ登録シートの内容が月次カレンダーへ転記されます。  
   - 反映後に数字や日付が正しいか確認し、必要があればデータ登録シートで修正して再度ボタンを押します。
4. **クリアと次の日の準備**  
   - 入力を一新したいときは「入力をクリア」ボタンを押すと、データ登録シートの入力欄が空になります。  
   - これで次の日の入力準備が整います。

## よくある質問
- **予定が読み込まれない**: Outlook が起動しているか、対象の日付に予定が入っているか確認してください。
- **分類や作業コードが表示されない**: 「統合マスタ」の一覧に情報が不足していないか確認し、必要なら初期設定ボタンを再度押してください。
- **月次データの列が足りない**: 初期設定ボタンを再度押すと、最新の列構成に整います。
